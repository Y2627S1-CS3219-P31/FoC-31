# Sealed Secrets

This directory holds committed [Bitnami SealedSecret](https://github.com/bitnami-labs/sealed-secrets) manifests for the EC2 cluster, generated by `../secrets/seal-secrets.sh` and synced by ArgoCD.

## Public cert

The team must place the sealed-secrets controller's **public** cert at `pub-cert.pem` (produced by `sealed-secrets-keygen.sh`).
It is used only to encrypt and is excluded from the ArgoCD sync.

## Sealed manifests

`seal-secrets.sh` reads the plaintext `../secrets/secrets.env`, builds each Secret, and seals it with `pub-cert.pem` into `<namespace>-<name>.yaml`.
Each real `*.yaml` is produced by a team member holding the key and committed separately (none ship in this PR).

## Deletion is manual

Every SealedSecret carries `argocd.argoproj.io/sync-options: Prune=false`, so removing a sealed file here does **not** delete the live Secret in the cluster.
Deleting a Secret is a deliberate manual step.
